# 📚 Révision Quiz - Développement Personnel & Soft Skills

Une petite app **hors ligne** pour réviser les quiz directement depuis ton téléphone.
Pas de serveur, pas d'installation, pas de connexion internet nécessaire.

## ✨ Ce que ça fait

- **6 séries de quiz** (blocs A, B, C, D et F en 2 parties), 59 questions/réponses (corrigé officiel)
- Mode **flashcards** : tu lis la question, tu réfléchis, tu touches la carte pour révéler la réponse
- Tu marques chaque carte **✅ Acquis** ou **🔁 À revoir**
- **Tout réviser** : toutes les questions mélangées
- **À revoir** : ne reprend que les cartes que tu as ratées
- **Progression sauvegardée** automatiquement sur ton téléphone (localStorage)
- **Mode sombre / clair**
- Lisible, simple, rapide

## 📱 Comment l'utiliser sur ton téléphone

1. Récupère le fichier **`index.html`** (envoie-le toi par mail / WhatsApp / Google Drive, ou télécharge-le depuis le repo).
2. Ouvre-le avec ton navigateur (Chrome, Safari...).
3. *(Optionnel)* Menu du navigateur → **« Ajouter à l'écran d'accueil »** : il s'ouvrira comme une vraie app, en plein écran.

Une fois ouvert une fois, il fonctionne **sans connexion**.

## 🔒 Confidentialité

Tout reste sur ton appareil. Aucune donnée n'est envoyée nulle part.
